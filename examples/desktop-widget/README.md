# Desktop widget example

Generated by the development CLI:

<!-- doctest: illustrative reason="The checked-in example already exists; the six generated scaffold variants are built and tested separately." -->
```bash
astra-plugin new desktop-widget-demo --lang rust --template desktop-widget --ui vanilla --output examples/desktop-widget
```

This example uses the repository-local Rust SDK and Astra's installed UI Kit.
The desktop widget runtime is prepared in source and needs a matching development
Astra. The generated Kit floor does not establish a released widget runtime.

Run `astra-plugin test .`, then `astra-plugin dev .` with Astra running.
On Home, add **Instance counter** twice and choose Compact or List. Each copy has
independent title/color/limit settings and persistent count. Menu opens a host
popover with a nested Select; Details opens a host modal. Configure uses standard
fields and the advertised settings view against the same draft. Save applies it,
Cancel discards it. Backend reports the instance ID automatically attached by Astra.
Preview is read-only. All views share index.html; viewId selects a surface and
formatId the placed format.

For a React frontend, scaffold another project with `--ui react` and run
`bun install --frozen-lockfile` in frontend before building. The same backend
contract works in Rust, Python and TypeScript. The overlay is outside this example.
See [the guide](../../docs/en/4-sdk/desktop-widgets.md).
