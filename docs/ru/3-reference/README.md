# Справочник

> Перевод. Источник истины — [docs/en](../../en/3-reference/README.md); при расхождении верна английская версия.

Два уровня, и разница важна.

## Сгенерировано — не может разойтись

Эти страницы производит [`tools/docgen`](../../../tools/docgen/) из кода,
который они описывают, и CI запускает `python3 tools/docgen/gen.py --check`:
зафиксированная страница, отличающаяся от свежей генерации, роняет сборку с
диффом. Страница CLI генерируется *запуском* `astra-plugin --help`, а не
разбором `main.rs`, потому что второй парсер для derive-макросов clap — это
ещё одна вещь, которая может молча разойтись с инструментом.

Они лежат на директорию выше, в [`../reference/`](../reference/) — именно
туда их пишет генератор.

| Страница | Из чего сгенерирована |
|---|---|
| [`plugin.toml`](../reference/manifest.md) | `astra-plugin-manifest` — крейт, которым демон разбирает манифесты |
| [CLI](../reference/cli.md) | определения `clap`, через запуск бинарника |
| [Протокол](../reference/protocol.md) | [`proto/plugin.proto`](../../../proto/plugin.proto) |
| [Ошибки](../reference/errors.md) | таксономия ошибок во всех трёх SDK |
| [Паритет хуков](../reference/parity.md) | [`spec/hooks.yaml`](../../../spec/hooks.yaml) — 35 хуков, 3 SDK |

Таблицы хуков по каждому SDK, отрисованные из той же спецификации:
[Rust](../hooks/rust.md) · [Python](../hooks/python.md) ·
[TypeScript](../hooks/typescript.md).

## Написано вручную — проверено человеком

Две страницы описывают то, что ни один генератор не может считать из типа:
что разрешение *значит* для пользователя, которого просят его выдать, и как
три разные вещи, называемые «конфигом», складываются вместе.

| Страница | |
|---|---|
| [Разрешения](permissions.md) | Каждый id, что он даёт, и как написать `reason` |
| [Конфигурация и поля настроек](config-fields.md) | `[config]`, типизированные настройки и хуки полей TTS/STT |
| [Локализация](localisation.md) | `locales/<code>.json`, маркер `$key` и где срабатывает проверка английского — **только на английском** |

Каждый пример кода на этих страницах выполняется в CI через
[`docs/tools/doctest.py`](../../tools/doctest.py).
