## PluginHostService — плагин → демон

Демон их реализует; вы их вызываете.

**Здесь одной возможности недостаточно.** Это вызовы, которые вы делаете в
демон, и демон отвечает на них исходя из *выданного* набора разрешений
(§5.6). Объявление возможности говорит, к какой функции относится вызов;
объявление разрешения — это то, на что соглашается пользователь. Плагин,
объявивший только возможность, получит `permission_denied` на машине
пользователя. `none` означает, что любой плагин может вызывать это всегда.

| RPC | Возможность | Разрешение | Обяз. | Поток | Статус | Что делает |
|---|---|---|---|---|---|---|
| `Register` | `core` | `none` | обязателен | unary | stable | Рукопожатие: предъявить токен запуска, получить токен сессии для этого плагина. |
| `GetPluginSelfConfig` | `core` | `none` | опционален | unary | stable | Прочитать собственные сохранённые настройки этого плагина. |
| `PluginLog` | `core` | `none` | опционален | unary | stable | Записать строку в буфер логов демона, который читает панель логов плагина. |
| `GetDaemonInfo` | `core` | `none` | опционален | unary | stable | Версия демона, состояние и порт gRPC. |
| `SetVariable` | `core` | `set_variable` | опционален | unary | stable | Опубликовать переменную, которую могут читать команды и другие плагины. |
| `SubscribeEvents` | `event_handlers` | `subscribe_events` | обязателен | server | stable | Отфильтрованный поток событий демона; вся возможность event_handlers. |
| `FireTrigger` | `triggers` | `fire_trigger` | обязателен | unary | stable | Запустить один из типов триггеров этого плагина и выполнить все слушающие команды. |
| `SendChatMessage` | `client` | `send_chat_message` | обязателен | server | stable | Отправить сообщение чата от имени этого плагина и стримить ответ ассистента обратно. |
| `PushToUi` | `ui_contributions` | `push_to_ui` | опционален | unary | stable | Отправить событие в собственные iframe этого плагина — обратный путь для CallFromUi. |
| `SetThemeContribution` | `ui_contributions` | `set_theme_contribution` | опционален | unary | stable | Внести цвета, обои и шейдер в активную тему Astra. |
