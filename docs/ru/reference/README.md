# Справочник

Сгенерировано. Каждая страница в этом каталоге — функция от исходного кода
в этом репозитории, отрисованная заново `python3 tools/docgen/gen.py` и
сверяемая на расхождение в CI той же командой с `--check`. Ручное
редактирование любой из них роняет сборку.

В этом и суть: справочный уровень — та часть документации, которую никто
не перечитывает против исходника, поэтому именно она не должна зависеть от
того, что кто-то это сделает.

| Страница | На что отвечает | Из чего выведена |
|---|---|---|
| [`cli.md`](./cli.md) | `astra-plugin`: каждая команда, аргумент и флаг | определения `clap` бинарника CLI |
| [`manifest.md`](./manifest.md) | `plugin.toml`: каждый раздел и поле | `astra-plugin-cli/vendor/astra-plugin-manifest` |
| [`protocol.md`](./protocol.md) | поверхность gRPC: сервисы, RPC, потоки, разрешения | `proto/plugin.proto` + `spec/hooks.yaml` |
| [`errors.md`](./errors.md) | таксономия ошибок, во всех трёх SDK | enum в proto + модуль ошибок каждого SDK |
| [`parity.md`](./parity.md) | какой хук привязан в каком SDK | `spec/hooks.yaml` |

## Чего здесь нет

**Прозы.** Всё, что объясняет *почему* или проводит вас через что-то,
написано вручную и живёт вне этого каталога. У генератора нет мнений.

**Ничего непроверенного.** Страница здесь утверждает только то, что её
генератор смог прочитать из исходника. Там, где факт живёт в демоне Astra,
а не в этом репозитории — например, какое разрешение закрывает каждый RPC
хоста, — страница говорит, какой зафиксированный файл его несёт и какое
правило паритета привязывает этот файл к демону.
