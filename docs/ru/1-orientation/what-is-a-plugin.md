# Что такое плагин

> Перевод. Источник истины — [docs/en](../../en/1-orientation/what-is-a-plugin.md); при расхождении верна английская версия.

Плагин — это **отдельная программа**, которую запускает демон Astra и которая
общается с демоном по gRPC на localhost. Это не библиотека, она не загружается
в адресное пространство Astra, и это не скрипт, который Astra интерпретирует.
Astra запускает её так же, как это сделал бы шелл, — с аргументами командной
строки, — а останавливает, попросив завершиться, и убивает группу процессов,
если та не завершилась сама.

Этот единственный факт определяет почти всё остальное:

- **Писать можно на чём угодно**, что умеет gRPC. Здесь поставляются три SDK —
  Rust, Python, TypeScript — и они находятся в состоянии
  [полного паритета](../reference/parity.md): все 35 хуков во всех трёх.
- **У плагина ваши права, а не меньшие.** См. [модель безопасности](security.md).
- **Он плохо переживает собственные баги, а Astra — вообще никак.** Паника
  внутри обработчика перехватывается и возвращается как ошибка, а не убивает
  процесс (`astra-plugin-sdk/src/panics.rs`); падение всего процесса
  обнаруживается проверкой здоровья демона в течение 15 секунд.

## Два направления

Всё, что делает плагин, относится к одному из двух направлений — это отдельные
системы с отдельными именами в `plugin.toml`.

| | Направление | Раздел манифеста | Отвечает на |
|---|---|---|---|
| **Возможности (Capabilities)** | демон → плагин | `[capabilities]` | Что плагин реализует и что Astra может вызвать *внутри* него |
| **Разрешения (Permissions)** | плагин → демон | `[permissions]` | Какие RPC хоста плагин может вызывать *наружу* |

Раньше для обоих было одно слово, из-за чего `dom_access` — самое опасное, что
есть в системе, — оказывался тем, что плагин выдавал сам себе, просто объявив
его. Теперь это два разных слова. Объявление `[capabilities] event_handlers =
true` не даёт права подписываться на события; это делает
`[permissions] subscribe_events`, и только после согласия пользователя.

`[permissions]` работает по принципу **запрещено всё, что явно не разрешено**:
без раздела вовсе плагин может вызывать только `Register`, `PluginLog`,
`GetPluginSelfConfig` и `GetDaemonInfo` и ничего больше
([`spec/permissions.md` §2](../spec/permissions.md)).

## Десять возможностей

Каждый ключ — булев, по умолчанию `false`, и обязывает вас обслуживать
некоторые хуки. В правой колонке — *обязательные*; необязательные — в
[таблице паритета](../reference/parity.md).

| Ключ `[capabilities]` | Чем становится ваш плагин | Хуки, которые нужно обслужить |
|---|---|---|
| `tools` | набор функций, которые может вызывать модель | `ListTools`, `CallTool` |
| `tts` | провайдер синтеза речи в настройках голоса | `TtsSynthesize`, `TtsListVoices` |
| `stt` | провайдер распознавания речи | `SttProcess`, `SttGetLanguages` |
| `ai_provider` | бэкенд модели | `AiComplete` |
| `actions` | шаги в редакторе команд | `ExecuteAction`, `GetPluginActionTypes` |
| `triggers` | типы триггеров, на которые могут подписываться команды | `GetPluginTriggerTypes`, `FireTrigger` |
| `ui_contributions` | панели, страницы и оверлеи в окне Astra | `GetUiContributions` |
| `event_handlers` | подписчик на события демона | `SubscribeEvents` |
| `client` | собственный клиент чата | `SendChatMessage` |
| `dom_access` | код, выполняющийся внутри окна Astra | ни один — это решение об отрисовке, а не хук |

Источник: [`reference/manifest.md`](../reference/manifest.md), сгенерировано
из крейта, которым демон разбирает ваш манифест. `ui_panels` — не возможность
и никогда ей не была: три примера из поставки объявляли её, serde тихо
отбрасывал неизвестный ключ, и единственным симптомом было то, что
`astra-plugin check` сообщал об отсутствии всех возможностей вообще. Именно
поэтому `[capabilities]` отклоняет неизвестные ключи.

## Как выглядит манифест

Самый маленький полезный манифест — плагин с инструментами, без разрешений и
без ничего лишнего:

<!-- doctest: toml-manifest -->
```toml
[plugin]
id = "dice-roller"
name = "Dice Roller"
version = "0.1.0"
description = "Roll dice from chat."
author = "You"
license = "MIT"

[entry]
command = "target/release/dice_roller"

[capabilities]
tools = true
```

Плагин, который срабатывает по триггеру, обязан запросить разрешение, а
`reason` — это то, что пользователь прочтёт, когда Astra попросит его дать
согласие:

<!-- doctest: toml-manifest -->
```toml
[plugin]
id = "dice-roller"
name = "Dice Roller"
version = "0.1.0"
description = "Roll dice, and fire a trigger when one comes up."
author = "You"
license = "MIT"
homepage = "https://github.com/you/dice-roller"

[entry]
command = "target/release/dice_roller"

[capabilities]
tools = true
triggers = true

[permissions]
fire_trigger = { reason = "Fires the trigger you configure when a roll completes" }
```

Каждый раздел и ключ: [`reference/manifest.md`](../reference/manifest.md).

## Чего плагин не может

- **Не может выдать себе разрешение — после установки.** Раздел
  `[permissions]` — это запрос. Для плагина, установленного из реестра или
  импортированного как файл, выданный набор разрешений вычисляет демон, исходя
  из того, откуда плагин взялся, и хранит его там, куда плагин не может
  писать, — сам манифест лежит в каталоге плагина, который плагин может
  редактировать. **Сайдлоаднутый плагин — исключение**: на этом уровне
  манифест *и есть* запись о согласии, и потолка нет, так что плагин может
  расширить собственные разрешения, отредактировав собственный файл. См.
  [модель безопасности](security.md#откуда-взялся-плагин--определяет-его-потолок).
- **Не может напрямую достучаться до `ChatService` Astra.** Токен сессии,
  который плагин получает при регистрации, ограничен `PluginHostService`.
  Управление ходом ИИ идёт через `SendChatMessage`, которое закрыто
  разрешением `send_chat_message` и относится к высокорисковым.
- **Не может полагаться на немаршрутизированный хук.** Хук может существовать
  в proto и во всех трёх SDK и не иметь точки вызова у демона: сегодня это
  `TtsSynthesizeStream`. Реализовать его — бесплатно; полагаться на то, что его
  вызовут, не поддерживается, пока [таблица паритета](../reference/parity.md)
  не скажет `live`.
- **Не может быть установлен на платформу, для которой у него нет бандла.**
  См. [платформы](platforms.md).
