| [Deutsch](de/README.md) · [Español](es/README.md) · [日本語](ja/README.md) · [Русский](ru/README.md) · [Українська](uk/README.md) · [简体中文](zh/README.md) | Translations of the current English pages. Same 37 files, same structure, checked for structure — not for meaning |

Six translations, all cut from the English pages as they stand today. Each is a
file-for-file mirror: same 37 pages, same paths, same headings, same order. Every
page opens by saying it is a translation and that English wins on disagreement.

## What CI can and cannot tell you about a translation

CI proves the *structure*: that each locale has exactly the pages `docs/en` has
([`mirror.py`](tools/mirror.py)), that every link in every language resolves to a
file and a heading that exist ([`linkcheck.py`](tools/linkcheck.py)), and that
every code sample in every locale still runs ([`doctest.py`](tools/doctest.py)).
Identical samples are executed once and reported as `identical to` the English
original, so a sample that drifted in translation is re-run on its own merits
rather than passing on the English one's credit.

CI cannot prove the *meaning*. Nothing here detects a semantic drift in a language
the maintainer cannot read. That is why English is canonical rather than merely
first: it is the one version whose claims are checked against the code.

This is also why nothing was translated until the English pages were correct. The
audit that started the rewrite found ~28 factually false claims in the English
pages alone, and the previous translation round had copied each of them into
every language before anybody noticed. Translating first is how twenty-eight
errors became a hundred and ninety-six.

## For maintainers

| | |
|---|---|
| `docs/en/reference/` | Generated by `python3 tools/docgen/gen.py`. CI runs `--check` |
| `docs/en/parity.md`, `docs/en/hooks/` | Generated by `python3 tools/parity/gen.py` from `spec/hooks.yaml` |
| `docs/en/spec/` | Normative specifications, hand-written and reviewed |
| everything else under `docs/en/` | Written, and every code sample in it is executed by `python3 docs/tools/doctest.py` |
| every other `docs/<locale>/` — [`docs/tools/locales.py`](tools/locales.py) says which | Translations. Hand-maintained, including the mirrors of the generated pages — the generators emit English only |
