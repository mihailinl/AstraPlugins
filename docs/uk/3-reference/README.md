# Довідник

> Переклад. Джерело істини — [docs/en](../../en/3-reference/README.md); за розбіжності відповідає англійська версія.

Два рівні, і різниця важлива.

## Згенеровано — не може розійтися

Ці сторінки виробляє [`tools/docgen`](../../../tools/docgen/) з коду, який
вони описують, і CI запускає `python3 tools/docgen/gen.py --check`:
зафіксована сторінка, що відрізняється від свіжої генерації, валить збірку з
діффом. Сторінка CLI генерується *запуском* `astra-plugin --help`, а не
розбором `main.rs`, тому що другий парсер для derive-макросів clap — це ще
одна річ, яка може мовчки розійтися з інструментом.

Вони лежать на каталог вище, в [`../reference/`](../reference/) — саме туди
їх пише генератор.

| Сторінка | З чого згенеровано |
|---|---|
| [`plugin.toml`](../reference/manifest.md) | `astra-plugin-manifest` — крейт, яким демон розбирає маніфести |
| [CLI](../reference/cli.md) | визначення `clap`, через запуск бінарника |
| [Протокол](../reference/protocol.md) | [`proto/plugin.proto`](../../../proto/plugin.proto) |
| [Помилки](../reference/errors.md) | таксономія помилок у всіх трьох SDK |
| [Паритет хуків](../reference/parity.md) | [`spec/hooks.yaml`](../../../spec/hooks.yaml) — 35 хуків, 3 SDK |

Таблиці хуків для кожного SDK, відрендерені з тієї самої специфікації:
[Rust](../hooks/rust.md) · [Python](../hooks/python.md) ·
[TypeScript](../hooks/typescript.md).

## Написано вручну — перевірено людиною

Дві сторінки описують те, що жоден генератор не може зчитати з типу: що
дозвіл *означає* для користувача, якого просять його видати, і як три різні
речі, що звуться «конфігом», складаються разом.

| Сторінка | |
|---|---|
| [Дозволи](permissions.md) | Кожен id, що він дає, і як написати `reason` |
| [Конфігурація і поля налаштувань](config-fields.md) | `[config]`, типізовані налаштування і хуки полів TTS/STT |
| [Локалізація](localisation.md) | `locales/<code>.json`, маркер `$key` і де спрацьовує перевірка англійської — **лише англійською** |

Кожен приклад коду на цих сторінках виконується в CI через
[`docs/tools/doctest.py`](../../tools/doctest.py).

## Нормативні специфікації

Для тих, хто реалізує верифікатор, пакувальник або реєстр, а не плагін. Це
документи в дусі RFC 2119 з еталонними векторами, а не посібники.
