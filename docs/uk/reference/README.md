# Довідник

Згенеровано. Кожна сторінка в цьому каталозі — функція від вихідного коду в
цьому репозиторії, відрендерена заново `python3 tools/docgen/gen.py` і
звірювана на розбіжність в CI тією самою командою з `--check`. Ручне
редагування будь-якої з них валить збірку.

У цьому й суть: довідковий рівень — та частина документації, яку ніхто не
перечитує проти вихідника, тому саме вона не повинна залежати від того, що
хтось це зробить.

| Сторінка | На що відповідає | З чого виведена |
|---|---|---|
| [`cli.md`](./cli.md) | `astra-plugin`: кожна команда, аргумент і прапорець | визначення `clap` бінарника CLI |
| [`manifest.md`](./manifest.md) | `plugin.toml`: кожен розділ і поле | `astra-plugin-cli/vendor/astra-plugin-manifest` |
| [`protocol.md`](./protocol.md) | поверхня gRPC: сервіси, RPC, потоки, дозволи | `proto/plugin.proto` + `spec/hooks.yaml` |
| [`errors.md`](./errors.md) | таксономія помилок, у всіх трьох SDK | enum у proto + модуль помилок кожного SDK |
| [`parity.md`](./parity.md) | який хук прив'язаний у якому SDK | `spec/hooks.yaml` |

## Чого тут немає

**Прози.** Усе, що пояснює *чому* або проводить вас крізь щось, написано
вручну і живе поза цим каталогом. У генератора немає думок.

**Нічого неперевіреного.** Сторінка тут стверджує лише те, що її генератор
зміг прочитати з вихідника. Там, де факт живе в демоні Astra, а не в цьому
репозиторії — наприклад, який дозвіл закриває кожен RPC хоста, — сторінка
каже, який зафіксований файл його несе і яке правило паритету прив'язує
цей файл до демона.
